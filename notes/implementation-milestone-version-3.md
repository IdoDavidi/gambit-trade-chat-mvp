## Implementation Milestone 3

### Goal

Introduce a deterministic business logic layer.

### Motivation

Milestone 2 stores structured state but still hardcodes state updates inside App.tsx.

The architecture should move business logic out of UI components.

### Changes

Created:

src/tools/interpretTrade.ts

The interpretTrade tool accepts a user message and returns a TradeState.

Example:

Input:

Trade LeBron to Boston

Output:

{
  teams: [
    "Los Angeles Lakers",
    "Boston Celtics"
  ],

  players: [
    "LeBron James"
  ]
}

### Supported Interpretations

LeBron

Output:
- Los Angeles Lakers
- Boston Celtics
- LeBron James

Curry

Output:
- Golden State Warriors
- Miami Heat
- Stephen Curry

Unknown messages

Output:
- Empty teams
- Empty players

### Architectural Outcome

Before:

ChatPanel
→ App State
→ TradeMirror

After:

ChatPanel
→ interpretTrade Tool
→ TradeState
→ TradeMirror

### Importance

This establishes the same execution pattern that future LLM tools will follow.

Future target:

ChatPanel
→ LLM Harness
→ Tools
→ TradeState
→ TradeMirror
